BIMBEL RUMAH NARAYA — VERSI GRATIS + SEO

Isi:
- index.html = website utama
- robots.txt = petunjuk untuk mesin pencari
- sitemap.xml = peta halaman untuk mesin pencari
- logo.jpg = logo
- poster_tk_sd.jpg = poster TK & SD
- poster_smp.jpg = poster SMP

Hosting gratis yang disarankan:
Cloudflare Pages.

Setelah website online:
1. Buka Google Search Console.
2. Tambahkan properti URL website.
3. Verifikasi kepemilikan.
4. Kirim sitemap.xml.
5. Minta Google mengindeks halaman utama.

Catatan:
Alamat canonical dan sitemap menggunakan https://rumahnaraya.pages.dev/ sebagai contoh target.
Jika Cloudflare memberi alamat berbeda, ganti URL tersebut pada index.html, robots.txt, dan sitemap.xml.
